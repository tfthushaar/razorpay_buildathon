# Settlement Reconciliation Copilot — frontend

React + TypeScript dashboard for the Razorpay AI Buildathon Track 04 submission. Expects the backend
running on `http://localhost:8000` (override via `VITE_API_BASE_URL`).

```bash
npm install && npm run dev
```

Full setup, real-provider configuration, and deployment: [docs/SETUP.md](../docs/SETUP.md).
